# SSH Folder Sync

[English](README.md) · 简体中文

### 准备工作

需要 VS Code 1.85+、扩展运行主机可用的 OpenSSH，以及目标服务器上的 Python 3。每条连接可选择 python3、python 或 py -3。支持 Linux/POSIX 路径及 Windows 盘符路径。浏览和同步要求密钥或 ssh-agent 免交互认证；只有免密配置向导首次登录时在终端输入密码。

先在扩展运行主机的终端执行 `ssh 你的别名`，确认主机指纹并配置认证；再确认以下命令成功：

```sh
ssh -T -o BatchMode=yes 你的别名 "python3 --version"
```

### 新建连接与目录选择

1. 在资源管理器中打开 **SSH 目录同步**，选择“新建连接”。
2. 输入名称，选择本地目录。
3. 从当前扩展主机的 `~/.ssh/config` 选择 Host 别名，也可手动输入。支持明确的 Host 和常见 Include 文件；不会读取 Remote SSH 的自定义配置文件设置，通配 Host 不作为单独选项。
4. 选择“浏览远端目录”进入子目录、返回上级，最后选择当前目录；也可“手动输入路径（离线）”。
5. 离线保存不连接、不验证目录。打开历史连接或刷新时再验证、比较。

### 查看差异与勾选

目录在前、文件在后，名称自然排序。列表顶部独立显示本地和远端路径，悬停查看完整内容。

- 绿色 `=`：相同；红色 `!`：不同或类型冲突。
- 蓝色 `L`：仅本地；橙色 `R`：仅远端。
- 目录按完整子树汇总状态，有任何差异便显示不同。
- 取消勾选排除同步；取消目录会排除所有后代。每条连接独立保存排除项。
- 排除项仍参与扫描、MD5 比较和目录状态判断。
- 重新勾选被排除目录中的子项，会解除祖先目录的排除，其兄弟项也可能恢复勾选，请检查最终显示状态。
- 右键两端都存在的文件查看文本差异。远端是临时快照，编辑快照不会上传。

### 执行同步

标题栏刷新图标只比较；关闭图标返回历史列表。三点菜单依次为“本地 → 远端”“远端 → 本地”“新建连接”。

同步前重新扫描两端并计算 MD5，仅复制已勾选的差异文件、创建缺失目录；相同文件和已有目录跳过。确认框明确显示从哪台主机、哪个目录复制到哪里，数量包含需创建的目录。

**目标同名文件将被覆盖，不传播删除，不自动判断哪个版本较新。** 类型冲突需手动处理。进度通知支持取消，已完成的复制不回滚；扫描和同步期间请避免其他程序修改文件。

### 历史记录与远程环境

初始显示历史连接，按最近使用排序，点击进入比较；右键可编辑、重命名、删除。编辑支持离线保存。删除记录不会删除两端文件。

配置保存在扩展全局存储目录的 `connections.json`，包含名称、Host 别名、两端路径、排除项及最近使用时间，不保存密码、私钥、文件内容或 MD5 缓存。旧版工作区配置会一次性迁移。

**“本地”是扩展运行所在的主机，Remote SSH 环境下可能不是面前的电脑。** 各运行环境独立保存历史。复制前请核对确认框里的主机与路径。

### 常见问题与限制

- “没有需要同步的项目”：已勾选文件相同或差异项均被排除，流程会立即结束。
- 目录不存在：核对绝对路径、登录用户和目录权限，不要额外加 shell 引号。
- 连接失败：在相同运行环境测试上面的 BatchMode 命令。
- 扫描慢：当前仍遍历全部目录；未变化的文件复用持久化 MD5 缓存，排除项也参与比较。
- 错误详情：打开“输出 → SSH Folder Sync”，分享日志前隐去主机和路径信息。

不支持删除传播、自动监控、断点续传、合并或权限所有者同步；跳过/拒绝符号链接。单次 SSH 操作超时 120 秒。文件以 base64 整体装入内存，不适合超大文件和海量目录。尚未完成多系统真实 SSH 端到端测试。

### 源码与 MD5 缓存

运行源码位于 src/。英文为原文，中文翻译集中在 src/i18n.js。缓存位于扩展全局存储目录的 md5-cache 子目录，按两端路径和 SSH 连接隔离保存。大小、高精度修改时间、变更时间和文件标识未变时复用 MD5，否则重新读取内容。删除项随下一次成功扫描清理，仍需遍历目录及读取元数据。若修改内容但保留所有校验元数据，缓存无法识别；删除对应缓存文件可强制重算。

### SSH 配置辅助

历史记录右键和三点菜单提供“检查 SSH 连接”和“配置 SSH 免密登录”。首次登录、密钥路径和限制见 [SSH 专项指南](SSH-GUIDE.zh-CN.md)。
